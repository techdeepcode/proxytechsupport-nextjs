# Company Cluster — LLM / Agent Discovery Report

## Generated from the registry

Both files' Tech Companies sections are generated by
`scripts/gen-companies-llms.mjs` (compile registry → rewrite the section between its heading
and the next `## `). Re-run it after registry changes to keep the list in sync.

## llms.txt (service intro + full list)

`public/llms.txt` (after Core Service Pages) — a service-focused intro (technical/proxy
interview + job support; "not listed? share a JD"), the `/tech-companies/` directory link,
then **all 500 companies** as markdown links (`[Company Interview & Job Support](url): focus`).
Per request, the full list is included so agentic crawlers can index every employer.

## llms-full.txt (service description + full list by industry)

`public/llms-full.txt` (before the Service Catalogue) — identity, dashboard URL, what we
offer per company, then **all 500 companies grouped by the 23 industry categories**
(`Company — support-page URL — focus`), plus the independence statement.

## Robots / AI crawlers

`app/robots.ts` already explicitly allows the major AI crawlers (GPTBot, ClaudeBot,
PerplexityBot, Google-Extended, Bingbot, Applebot-Extended, CCBot, meta-externalagent,
MistralAI-bot, xAI/Grok, etc.) and exposes `/sitemap.xml`. The new pages are under `/` and
therefore already crawlable; no robots change required.

## September 2026 llms.txt v2 features evaluated

- **rel="alternate" type="text/markdown" / rel="describedby" per-page Markdown alternates:**
  evaluated and **not** implemented — the site is a static Next.js export without content
  negotiation, and adding per-page `.md` alternates for 200+ pages would risk duplicate-
  indexing and maintenance burden for marginal benefit. The curated root `llms.txt` +
  structured `llms-full.txt` remain the primary machine-readable signals, consistent with
  the rest of the site.
- Decision recorded here for future revisiting if the framework adopts a Markdown route.
