# Company Cluster — SEO Report

## Metadata (per hub)

Generated by `landingPageMetadata()` (`lib/site-seo.ts`) from each config — the same helper
every existing landing page uses:

- Unique `title`, `description`, `keywords` per company (seeded with the company name +
  roles + technologies). Verified: **0 duplicate titles** across the 218 hubs.
- Self-referencing `canonical` (`https://proxytechsupport.com/{slug}-career-support/`).
- hreflang `alternates` (en-US/CA/GB/AU/IE + x-default) — consistent with the site.
- `robots: { index: true, follow: true }`.
- Open Graph (`type: website`, title/description/url/siteName/image) + Twitter summary card.
- Dashboard uses the same helper + a distinct title/description.

## Canonicalization

- Every hub self-canonicalizes; no cross-canonical to a generic page.
- Canonicals are built in `data/companies/shared.ts` as `${BASE_URL}/${slug}/`, matching the
  Amazon/AWS/Azure pattern, so `verify-content-urls.mjs` behaviour is unchanged.

## Structured data

- `/tech-companies/`: `CollectionPage` + `ItemList` (all 500 entries, name + URL) +
  `BreadcrumbList`. Company entries are **not** marked as ProxyTechSupport's own
  Organization; no employer-affiliation schema.
- Hubs: `LandingPageTemplate` emits its standard WebPage/FAQ structured data (FAQPage from
  the config FAQs, which are genuine Q&A).

## Sitemaps

- `app/sitemap.ts` includes all 218 hubs automatically via `allLandingPages.map(canonical)`
  and `/tech-companies/` as a static route (priority 0.9). No noindex/redirect/placeholder
  URLs added.

## Robots / indexing

- `app/robots.ts` (unchanged) allows all crawlers incl. AI agents and exposes the sitemap.
- Only complete, unique, internally-linked pages are indexable; Tier D companies without a
  hub are **not** turned into thin indexable pages — they remain dashboard cards.

## Duplicate-content controls

- Unique per-company blurb (all 500 hand-written) leads each hub; registry-driven hubs also
  vary role/tech ordering deterministically by slug (`rotate`) to avoid verbatim sibling
  copy; hand-written rich facts for the 29 marquee employers.
- 0 duplicate hub titles; 0 duplicate hub slugs (validated).

## Brand safety

- Independence disclaimer in every hub's FAQ; no implied affiliation, no fabricated
  interview questions, no guarantees of interviews/employment.
