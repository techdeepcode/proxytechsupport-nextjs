# AI/ML Global SEO Cluster — Physical File Plan

Add-only expansion. Mirrors the existing Workday cluster pattern:
`data/*-pages.ts` (LandingPageConfig objects) → `LandingPageTemplate` → physical
`app/<slug>/page.tsx` generated by an idempotent gen script → auto-listed in sitemap
via `allLandingPages`.

## Infrastructure (no existing file broken)
- `data/aiml/shared.ts` — BASE_URL, LASTMOD, shared highlights, FAQ builders, config builder helpers, shared related-link pools. **No page objects.**
- `data/aiml/index.ts` — imports every batch array, exports `allAiMlClusterPages`.
- `data/landing-pages.ts` — add ONE import + ONE `...allAiMlClusterPages` spread into `allLandingPages` (additive; nothing removed).
- `scripts/gen-aiml-cluster-pages.mjs` — writes `app/<slug>/page.tsx` for every cluster slug; skips any existing dir (idempotent, never overwrites).

## Per-page quality (enforced by builders + unique inputs)
Unique title (<60), description (<155), canonical, H1, 5–8 H2 sections, painIntro,
heroVariant, 6 unique use cases, 5–7 unique FAQs, proxy section, related links,
breadcrumbs, FAQPage + Service + BreadcrumbList JSON-LD (template), robots index/follow.

## Verify after each batch
`node scripts/gen-aiml-cluster-pages.mjs` then `npx tsc --noEmit` (typecheck) and finally `npm run build`.
